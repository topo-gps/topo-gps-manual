Exporting visible map
=====================
To export the currently visible map and the items on it, first open the maps pop-up via Menu > Maps. Then go to the top, there is the entry 'Export visible map'.
If you tap this item, a pop-up will appear, in which you can choose the items you want to export. 
<APPLE>If routes, points and layers are shown you can select 'Geodata' to export them.</APPLE>
<ANDROID>If routes and points are shown you can select 'Geodata' to export them.</ANDROID>
If you want to have a map in pdf, jpeg or png format you have to tick 'Map'. Then you can choose the settings icon in the top right of the share pop-up to set the file formats.
<APPLE>
If you export a map you can set the 'Annotate map' switch to be able to draw annotations on the map before sharing the map. It can be useful to add helpfull remarks here.
</APPLE>
Finally you can tap the 'Export' button in the bottom of the pop-up to export the items. A share sheet will appear in which you can choose to send the exported items.

An alternative of exporting the visible map is :ref:'selecting a part of the map <ss-map-select>', and then tap the 'Export' button. This allows you to more easily determine the area of objects you want to export.
